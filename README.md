# 🏨 Hotel Oasis del Sol - Sistema de Reservas

Aplicación web para reserva de habitaciones de hotel desarrollada con PHP, MySQL, HTML y CSS.

## Funcionalidades

- Búsqueda de habitaciones por tipo y precio
- Visualización de habitaciones disponibles con fotos
- Formulario de reserva con datos del huésped
- Registro automático de clientes en base de datos
- Confirmación de reserva exitosa

## Tecnologías

- PHP
- MySQL (5 tablas)
- HTML, CSS, Bootstrap 5
- XAMPP

## Instalación

1. Clonar el repositorio
2. Importar `hotel_oasis.sql` en phpMyAdmin
3. Colocar los archivos en `xampp/htdocs/hotel_oasis`
4. Ejecutar en `http://localhost/hotel_oasis`
